# 永雏塔菲 (Taffy) 独立跨平台桌宠

🐰 专为雏草姬打造的永雏塔菲桌面宠物，支持 Windows 和 macOS 原生双端，零紫边、高帧率透明合成。

![Taffy](assets/icon.png)

## ✨ 特性一览
- 💎 **32位真彩色透明合成**：彻底摒弃传统洋红（#FF00FF）抠图，边缘绝无紫边毛刺；
- ⏱️ **平缓呼吸律动**：动作帧率经过逐行精校（待机 190ms/帧），动作流畅自然、不闪烁；
- 💬 **萌系贴头气泡**：台词气泡精准贴在塔菲发顶，支持多倍率缩放（0.75x ~ 1.5x）动态对齐；
- 🎮 **丰富互动**：鼠标拖拽悬空挣扎、单击欢呼跳跃、自动边缘漫步巡游。

## 📦 下载与安装
前往项目的 [Releases](../../releases) 页面直接下载对应平台安装包：
- **Windows 用户**：下载 `.exe` 单文件便携版，双击即玩；
- **macOS 用户**：下载 `.dmg` 磁盘镜像安装包（区分 Apple Silicon M系列 与 Intel 处理器），挂载后拖入 `Applications` 即可畅玩。

### macOS 首次打开提示“已损坏”或“拦截”解决方法：
在终端执行以下命令解除 Gatekeeper 隔离：
```bash
sudo xattr -cr /Applications/永雏塔菲桌宠.app
```
